## 🚀 Overview

**Krishi Sahay** ("Agriculture Helper") is a comprehensive AI-powered platform transforming traditional farming into smart agriculture. We combine **cutting-edge AI**, **IoT sensors**, **computer vision**, and **community-driven solutions** to help farmers increase yields, reduce losses, and make data-driven decisions.

### 🎯 What Makes Us Different?

| Traditional Farming | 🌾 Krishi Sahay |
|---------------------|------------------|
| ❌ Manual disease identification (slow, error-prone) | ✅ **AI-powered instant disease detection** with 95%+ accuracy |
| ❌ Guesswork-based decisions | ✅ **Data-driven insights** from IoT sensors + weather AI |
| ❌ Middlemen exploitation | ✅ **Direct marketplace** with real-time pricing |
| ❌ Isolated farmers | ✅ **Community clans** for knowledge sharing |
| ❌ Limited expert access | ✅ **24/7 AI assistant** with 10+ specialized tools |

## 💡 Problem We Solve

### The Agricultural Crisis

🌍 **Global Impact**: Plant diseases cause **20-40% annual yield losses**, costing farmers **$220 billion yearly** (FAO, 2021)

🇧🇩 **Local Context**: In Bangladesh:
- **16.5 million farmers** manage 70% of arable land
- **80% lack access** to agricultural extension services
- **40-60% profit** lost to middlemen exploitation
- **30-50% resource waste** due to poor monitoring

### Our Solution: AI-Powered Agriculture Ecosystem

We provide farmers with:
1. 🔬 **Instant Disease Detection** - Camera-based diagnosis in seconds
2. 🌡️ **Real-time Environmental Monitoring** - IoT sensors tracking soil, weather, and crops
3. 🤖 **Intelligent AI Assistant** - Natural language advisor with specialized farming tools
4. 💰 **Fair Marketplace** - Direct selling with transparent pricing
5. 🏘️ **Community Support** - Farmer clans for knowledge sharing and collective bargaining

### 2️⃣ 🔬 Advanced Disease Detection (YOLOv11 Computer Vision)

**The Problem**: Manual disease identification takes 7-14 days waiting for experts. By then, entire crops are lost.

**Our Solution**: Instant AI-powered diagnosis using smartphone camera

<details>
<summary><b>🦠 13 Disease Classes Supported</b></summary>

| Crop | Diseases Detected | Accuracy |
|------|-------------------|----------|
| 🍎 **Apple** | Black Rot, Rust, Scab | 96.2% |
| 🌽 **Corn** | Gray Leaf Spot, Common Rust, Northern Leaf Blight | 94.8% |
| 🍇 **Grape** | Black Rot, Leaf Blight (Esca) | 95.5% |
| 🥔 **Potato** | Early Blight, Late Blight | 97.1% |
| 🍅 **Tomato** | Bacterial Spot, Early Blight, Late Blight, Leaf Mold, Mosaic Virus | 95.9% |

**Training Data**: 54,000+ images from PlantVillage dataset

</details>

**How It Works**:
1. 📸 Farmer takes photo of diseased plant
2. 🧠 YOLOv11 model analyzes image in <2 seconds
3. 📊 Provides disease name, confidence score, severity
4. 💊 Recommends treatment options and preventive measures

**Input Methods**:
- 📷 **Image Upload** - Gallery photos or new captures
- 🎥 **Video Processing** - Continuous monitoring from video files
- 📹 **Live Camera** - Real-time detection via webcam/mobile camera

### 3️⃣ 🌡️ IoT Sensor Network (ESP32 Real-time Monitoring)

**The Problem**: Farmers check soil/weather manually, leading to delayed responses and resource waste.

**Our Solution**: Automated environmental monitoring with instant insights

**Hardware**: ESP32 microcontrollers with sensor array
- 🌡️ **Temperature** - Air & soil temperature
- 💧 **Humidity** - Atmospheric humidity & soil moisture
- ☀️ **Light Intensity** - Photosynthetically active radiation (PAR)
- 🧪 **Soil Chemistry** - pH levels, NPK nutrients

**Software Features**:
- ⚡ **Real-time Streaming** - WebSocket-based live data (sub-second latency)
- 📊 **Interactive Dashboard** - Chart.js visualizations with trend analysis
- 🔔 **Smart Alerts** - Automated notifications for critical conditions
- 📈 **Historical Analytics** - 30-day trends and pattern recognition
- 🤖 **ML Anomaly Detection** - Predicts issues before they occur

**Example Use Cases**:
- 💧 Automatic irrigation when soil moisture drops below threshold
- 🌡️ Frost warnings for sensitive crops
- 🧪 Fertilizer recommendations based on NPK levels

### 🔄 Data Flow Examples

<details>
<summary><b>Example 1: Disease Detection Flow</b></summary>

```
1. 📱 User uploads image via mobile app
2. 🌐 Frontend sends POST /api/detection/upload
3. 🖼️ Backend saves image, preprocesses with OpenCV
4. 🧠 YOLOv11 model analyzes image
5. 📊 Returns: {disease: "Late Blight", confidence: 0.96, treatment: [...]}
6. 💾 Saves detection to database for analytics
7. 📲 Frontend displays result with treatment recommendations
```

</details>

<details>
<summary><b>Example 2: AI Agent Conversation Flow</b></summary>

```
1. 🗣️ User asks: "What's the weather forecast for this week?"
2. 🌐 Frontend POST /api/agent/chat with message
3. 🤖 Gemini Pro analyzes intent → selects get_weather_forecast tool
4. 🛠️ LangGraph executes tool → fetches weather API data
5. 🧠 Gemini Pro synthesizes response in natural language
6. 📲 Returns: "Next 7 days show rain on Tue/Wed. Consider delaying harvest..."
7. 💬 Frontend displays in chat interface with TTS option
```

</details>

<details>
<summary><b>Example 3: IoT Sensor Data Flow</b></summary>

```
1. 🌡️ ESP32 reads sensor: Temperature = 28°C, Humidity = 65%
2. 📡 ESP32 sends data via WebSocket to backend
3. 💾 Backend stores in time-series database
4. 🔔 Checks thresholds → triggers alert if temperature > 35°C
5. 📊 Broadcasts to connected frontend clients via WebSocket
6. 📈 Frontend updates dashboard charts in real-time
7. 🤖 AI Agent can query sensor data when asked
```

</details>

We welcome contributions from developers, agricultural experts, and farming enthusiasts!

### How to Contribute

1. **Fork the Repository**
   ```bash
   git fork https://github.com/electr0x0/krishi_sahay_hackathon.git
   ```

2. **Create Feature Branch**
   ```bash
   git checkout -b feature/amazing-feature
   ```

3. **Make Your Changes**
   - Follow code style guidelines
   - Add tests for new features
   - Update documentation

4. **Commit with Meaningful Messages**
   ```bash
   git commit -m "feat: Add pest detection model"
   git commit -m "fix: Resolve WebSocket connection issue"
   git commit -m "docs: Update API documentation"
   ```

5. **Push to Your Fork**
   ```bash
   git push origin feature/amazing-feature
   ```

6. **Open Pull Request**
   - Describe your changes clearly
   - Reference related issues
   - Wait for review

### Contribution Areas

- 🐛 **Bug Fixes** - Report or fix issues
- ✨ **New Features** - AI models, IoT integrations, UI improvements
- 📚 **Documentation** - Improve guides, add translations
- 🧪 **Testing** - Write unit/integration tests
- 🌍 **Localization** - Translate to new languages
- 🎨 **Design** - UI/UX improvements
- 📊 **Data** - Contribute labeled crop disease images

### Code Style

**Frontend (TypeScript/React)**:
- Follow ESLint rules
- Use TypeScript strict mode
- Component naming: PascalCase
- Function naming: camelCase

**Backend (Python)**:
- Follow PEP 8 guidelines
- Use type hints
- Document functions with docstrings
- Class naming: PascalCase
- Function naming: snake_case
